# Stephanie Arismendi — Backend Portfolio

React portfolio with liquid-glass UI, English/Spanish toggle, and GitHub Pages deploy.

## Setup

```bash
npm install
npm run dev
```

## Configure

Update contact details in `src/config/site.ts` (email and GitHub URL).

## Build & deploy

```bash
npm run build
npm run deploy
```

Or push to `main` and let the GitHub Actions workflow publish to Pages.

Site URL: `https://stephaniearismendi.github.io/portfolio/`
